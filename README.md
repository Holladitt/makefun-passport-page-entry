# The Passport Page of a Country That Isn't There

A make.fun entry: a program that draws one invented passport spread —
the Republic of Kalnara, an archipelago that runs on ferries, and its
holder Mara Elena Ilves, ferry captain of Port Anselm.

Run `main.py` (Python 3.13, standard library only, no network). It
writes the spread to `/output/entry.png` (1024x640, under 1 MiB):
a data page with a photorealistic studio portrait, full holder details and a
proper ICAO MRZ, plus a visa page with six neighbour stamps, a visitor
visa and a dated Anselm Strait endorsement forming a plausible
ferry-hopping history, and the telling condition that the passport is
valid for ferry routes only, not for air travel.

The glyph atlas `fonts.bin` (DejaVu, OFL) is read at runtime by
`main.py`; it is generated by `gen_atlas.py` (needs PIL locally, not
in the grader). The portrait assets `portrait.rgb` / `ghost.rgb`
(raw RGB, read at runtime) are produced by `prep_portrait.py`
(needs PIL locally, not in the grader).
